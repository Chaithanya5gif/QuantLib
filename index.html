Introduction

Quantitative Finance in Modern C++

QuantLib is a comprehensive, open-source C++ framework for modeling, trading, pricing, and risk management in real-life quantitative finance.

⚡ C++17 Baseline 📜 BSD 3-Clause License 🌐 OSI Certified Open Source GitHub Repository

Core Framework Modules

📈
Financial Instruments
Options, swaps, bonds, forward contracts, credit derivatives, and exotic payoff structures.
⚙️
Pricing Engines
Analytical pricing, Black-Scholes, Heston, finite-difference solvers, and Monte Carlo engines.
📉
Term Structures
Yield curve bootstrapping, discount factors, zero rates, forward rates, and volatility surfaces.
📅
Date & Time Conventions
Financial calendars for global exchanges, business day conventions, and standard day-count fractions.
🧮
Math & Optimization
Linear algebra, 1D/multidimensional solvers, numerical integration, interpolations, and distributions.
💡
Practical Examples
End-to-end runnable walkthroughs: equity options, bond pricing, Bermudan swaptions, and CDS curves.

Quick C++ Overview

#include <ql/quantlib.hpp>
#include <iostream>
using namespace QuantLib;
int main() {
// Set evaluation date
Calendar calendar = TARGET();
Date today = Date(26, November, 2026);
Settings::instance().evaluationDate() = today;
// Define option parameters
Option::Type type(Option::Call);
Real underlying = 100.0, strike = 105.0;
Spread dividendYield = 0.01;
Rate riskFreeRate = 0.05;
Volatility volatility = 0.20;
Date maturity = today + 1 * Years;
std::cout << "Option maturity: " << maturity << std::endl;
return 0;
}
