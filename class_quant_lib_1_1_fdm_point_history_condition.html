Detailed Description

records the value at a given point of a one-dimensional mesher

The value is read off the solution with the same interpolation as Fdm1DimSolver, at each time the condition is applied. Placed nth in a step-condition composite, it records the value after the first n-1 conditions are applied.

The recorded values can drive a time-dependent boundary condition of a second solver, e.g. the value of the vanilla option on the barrier of a knock-in option.

The whole solution can also be kept at given times. For example, a discrete dividend can take a cum-dividend spot on the inactive surface of a knock-in option through the barrier; that node then takes its value from the active surface at the ex-dividend time.
